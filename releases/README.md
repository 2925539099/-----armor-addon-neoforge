## 安装

1. 安装 Minecraft **1.21.1** 的 **NeoForge**（21.1.244 或更高的 21.1.x）。
2. 把对应版本的 jar 放进 `.minecraft/mods/`。
3. 启动游戏即可，**不需要任何前置模组**。

## 选哪个版本？

- **新装玩家**：直接用最新的 **1.1.0**。
- **已在用 1.0.x 的存档**：升到 1.1.0 只是**新增**了木制盔甲，原有物品的注册 ID 全部没变，
  存档可以直接沿用。
- **回退到旧版**：1.0.0 与 1.0.1 之间只差羊毛盔甲的穿戴贴图，功能完全相同。
